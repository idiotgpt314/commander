# Free Growth Plan

## Free Distribution Channels

- GitHub Releases with short demo GIFs and distro install instructions
- AUR listing for Arch users
- Debian package downloads attached to GitHub releases
- Hyprland and Linux productivity communities
- Show HN / Hacker News launch post
- Product Hunt launch page
- demo clips on X, Reddit, and YouTube Shorts pointing to GitHub

## Positioning

Commander should be pitched as:

- a fast local AI launcher for Linux
- voice plus text with no ads
- configurable backends, not locked to one model vendor
- clean enough to replace ad hoc shell aliases and launcher clutter

## What To Publish

- 30 second summon demo
- one distro install walkthrough
- one packaging matrix image
- one "switch backend" demo
- one "hotkey to solved task" clip

## Low-Cost Growth Loop

1. publish a release
2. post the short demo
3. respond to every bug report quickly
4. turn solved issues into release notes
5. reuse those notes as launch content
